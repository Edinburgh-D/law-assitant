项目介绍
合同法智能助手是一个基于浏览器端SQLite数据库（SQL.js）的法律条款查询和学习系统，采用纯前端架构，无需后端服务器。
技术架构：
- 前端：HTML5 + CSS3 + JavaScript（原生）
- 数据库：SQL.js（浏览器端SQLite）+ IndexedDB持久化
- 功能模块：条目速查、学习中心、利益分析、案例展示
数据结构：
数据库包含5个核心表：
1. articles表：存储条款基本信息（id、章节、条款号、标题、原文内容、解读、甲方分析、乙方分析）
2. keywords表：条款关键词索引（用于搜索匹配）
3. cases表：相关案例（条款ID、案例标题、案情摘要、判决结果）
4. related_articles表：条款关联关系
5. notes和learning_progress表：用户笔记和学习进度
